# Método Agú — Visão Geral

## Princípio central

O planejamento de conteúdo não começa pelo calendário. Começa pela intenção.

Primeiro deve ser definido o que a marca precisa construir no ciclo. Depois são escolhidos os temas, os objetivos estratégicos, os recortes e os formatos.

Conteúdo bonito chama atenção. Conteúdo intencional constrói marca.

## Fórmula de cada conteúdo

**TEMA + OBJETIVO + RECORTE + FORMATO + AÇÃO**

- **TEMA** — Qual território da marca será acionado?
- **OBJETIVO** — Para que aquele conteúdo existe estrategicamente?
- **RECORTE** — Qual ideia específica será desenvolvida?
- **FORMATO** — Como a mensagem será entregue?
- **AÇÃO** — O que a pessoa deve pensar, sentir ou fazer depois?

## Onde cada parte do método está detalhada

- Territórios/temas recorrentes (linha editorial) e os filtros para validá-los → `criterios-de-conteudo.md`.
- Os cinco objetivos estratégicos de conteúdo (Autoridade, Conexão, Posicionamento, Crescimento, Oferta) → `pilares.md`.
- Critérios de escolha de formato (Foto, Vídeo, Carrossel, Card, Stories) → `criterios-de-conteudo.md`.
- Regra de distribuição do ciclo e processo de planejamento → `planejamento.md`.
